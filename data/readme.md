# Data folder

This folder will contain:
- Sample data
- Data dictionary
- Preprocessing outputs (later)

## Column explanations (for sample.csv)

- **flight_id** — a simple number used to identify each flight (1, 2, 3…)
- **airport** — the 4‑letter ICAO airport code (e.g., EGLL = London Heathrow)
- **scheduled_out** — the planned time the aircraft should leave the gate
- **actual_out** — the real time the aircraft left the gate
